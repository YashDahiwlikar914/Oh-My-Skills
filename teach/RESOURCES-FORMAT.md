# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Draw knowledge for explainers from here, not from parametric guesses. Wisdom comes from the communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for anything to do with periodisation, recovery, and intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit with moderation against bro-science. Use for programme critique and plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for real-time coaching feedback on lifts.
```

## Rules

- **Keep only high-trust sources.** Prefer primary sources, recognised experts, peer-reviewed work, and communities with strong moderation. Leave out any resource that is marketing dressed as education.
- **Annotate each entry.** A bare link is useless in three months. Add one line on what it covers and when to reach for it.
- **Group by Knowledge and Wisdom.** This mirrors the philosophy in [SKILL.md](./SKILL.md). A resource can appear in only one group.
- **Surface gaps explicitly.** If no good resource exists for an area the mission needs, write a `## Gaps` section listing what is missing. This drives future search.
- **Prune ruthlessly.** Remove a resource that turned out to be wrong, shallow, or off-mission instead of burying it. Five sharp sources beat thirty mediocre ones.
- **Record community preferences.** If the user opted out of joining communities, note it here so future sessions stop proposing them.
